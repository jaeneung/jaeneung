What is micro:bit? p. 122–123

💡
LED Display

25 tiny lights (5×5 grid). Shows letters, numbers, and pictures.

🔘
Buttons A & B

Two buttons on the sides. Press them to run code.

📳
Accelerometer

A sensor inside. It feels movement — like shaking or tilting.

🌡️
Temperature Sensor

Measures how hot or cold the air is.

Micro:bit's Buttons p. 128–130

You can make the micro:bit do something when you press a button.

🅰️
Button A pressed

Run code when button A is pushed.

🅱️
Button B pressed

Run code when button B is pushed.

🆎
A + B pressed

Run code when both buttons are pushed together.

Button code pattern

1def on_button_pressed_a():
2    basic.show_leds("letter A shape")
3input.on_button_pressed(Button.A, on_button_pressed_a)
4
5def on_button_pressed_b():
6    basic.show_leds("letter B shape")
7input.on_button_pressed(Button.B, on_button_pressed_b)
💡
The pass keyword is a placeholder. It means "nothing here yet — add your code!"

Micro:bit Responds on Shaking p. 131–132

1def on_gesture_shake():
2    basic.show_number(randint(1, 9))
3input.on_gesture(Gesture.SHAKE, on_gesture_shake)
🎲
randint(min, max) gives a random number between min and max (both included). Example: randint(1, 9) can give 1, 2, 3 … or 9.
